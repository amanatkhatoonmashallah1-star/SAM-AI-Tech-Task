# Task 3 & 5: Data Visualization & Votes Correlation Analysis
**Internship Track:** Data Analyst  
**Company:** SAM AI Technologies  

---

## 📌 Project Overview
This project delivers a multi-panel exploratory visual dashboard and statistical analysis investigating:
1. The relationship between total customer vote counts and aggregate restaurant ratings.
2. The distribution of ratings and price tier behavior across dining establishments.
3. Ranking of the highest and lowest engagement food outlets.

---

## 🛠️ Tech Stack
- **Python 3.10+**
- **Pandas** for data wrangling and statistical summary
- **Matplotlib & Seaborn** for multi-panel dashboards and regression modeling

---

## 📊 Key Findings
- **Positive Correlation:** Pearson correlation confirms that highly-rated restaurants attract significantly higher vote volumes, illustrating social proof in online dining decisions.
- **Delivery Impact:** Establishments offering online delivery demonstrate competitive pricing and consistent mid-to-high ratings across major metropolitan centers.

---

## 🚀 How to Run
```bash
pip install pandas matplotlib seaborn
python data_visualization_and_votes.py
```
